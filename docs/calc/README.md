# Розрахунки

Чистий Python 3, без залежностей. Запуск: `python3 <файл>`.

| Файл | Що робить |
|---|---|
| `verify_all.py` | **основний.** Зведений розрахунок одним послідовним набором припущень: струми, коефіцієнт трансформації, трансформатор, LV-міст, HV-каскад, бюджет втрат, ККД, охолодження, ресурси ESP32. Містить самоперевірку формул і перехресні перевірки (баланс потужності, B через два різні шляхи). |
| `lv_bridge.py` | детальний розбір LV-моста: виведення формул провідникових втрат, самоузгоджений розвʼязок Rds(Tj), ZVS, Miller-струм, мертвий час, вимоги до драйвера. |
| `audit.py` | перший прохід аудиту: базові струми, перевірка тверджень з початкового обговорення. |
| `sim.py` | числове інтегрування по періоду 50 Гц (перевірка, що втрати рахуються по RMS, а не по піку). |
| `audit2.py` | самоаудит: перерахунок з даними, звіреними по даталистах, і виправлення власних помилок. |

## Оцінки, які ще треба звірити вручну

Ці значення взяті як інженерні оцінки (даталисти Infineon і onsemi віддають HTTP 403
при автоматичному завантаженні):

- IRL40SC209: Qg при Vgs=12 В (взято 300 нК), Coss (4 нФ), Crss (1 нФ), Rth(j-c) (0.55 K/Вт),
  Id silicon/package limited;
- FAN7390: точний вихідний струм (взято 4.5 А з опису) і затримки розповсюдження;
- CoolMOS C7/CFD7: температурний коефіцієнт Rds(on) (взято ×2.2 при 125 °C);
- Vf body diode (0.9 В), Llk трансформатора (15 нГн), Rth(ETD59) = 8 K/Вт без обдуву.

У бюджеті втрат окремо позначені «мʼякі» позиції з похибкою ±50%: HV перемикальні,
вихідний фільтр, шини й конденсатори, аукс (разом ~47 Вт зі ~115–199 Вт).
Остаточні цифри може дати тільки ватметр на прототипі.
